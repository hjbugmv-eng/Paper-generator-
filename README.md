# Professional Paper Generator

A professional AI-powered school examination paper generator.

## Features

- School Name
- School Logo
- Exam Name
- Class
- Subject
- Date
- Time
- Total Marks
- Passing Marks
- MCQs
- Short Questions
- Conceptual Questions
- Analytical Questions
- Application Questions
- Long Questions
- Fill in the Blanks
- True / False
- Mathematics Questions
- Difficulty Selection
- Random Questions
- Answer Key
- Urdu RTL Support
- English LTR Support
- Paper Preview
- Print
- Save as PDF

## AI

The application can connect to an AI API.

API configuration is stored in:

api.js

Replace:

YOUR_API_URL_HERE

with the API endpoint.

Replace:

YOUR_API_KEY_HERE

with your API key.

Replace:

YOUR_MODEL_HERE

with the model name.

## Important

The AI should generate questions only from the lesson/content supplied by the user.

No unrelated information should be introduced.
